KQZL2-001 PM2.5+排风+蜂鸣器+灯光 (版本 1-14)

支持功能：
- PM2.5 检测
- PM2.5 超限自动排风和声光提醒
- 风扇、蜂鸣器、灯光控制
- WiFi/蓝牙远程控制为后续版本扩展

版本1功能说明：
1. STM32F103C8T6 单片机进行数据处理。
2. OLED 液晶显示空气 PM2.5 实时数据。
3. GP2Y1014AU 检测当前 PM2.5 粉尘浓度。
4. K1 切换自动/手动/阈值设置模式。
5. 手动模式下 K2 切换设备，K3 打开和关闭设备。
6. 阈值模式下 K2 选择 PM2.5 阈值，K3 加，K4 减。
7. 自动模式下 PM2.5 高于阈值时，风扇排风并启动蜂鸣器和灯光声光报警。

5. K1 切换自动/手动/阈值设置模式。
6. 手动模式下 K2 切换设备，K3 打开和关闭设备。
7. 阈值模式下 K2 选择某个阈值，K3 加，K4 减。
8. 自动模式下 PM2.5 高于阈值时，风扇排风并启动声光报警；温度高于阈值时，风扇排风并启动声光报警；湿度高于阈值时，风扇排风并启动声光报警。

构建指定版本 (1-14)：
cmake -S . -B build -G "Ninja" -DAPP_VERSION=5 -DCMAKE_TOOLCHAIN_FILE=D:/ProjectJBL/PerfabProj/project_template/cmake/stm32-gcc-toolchain.cmake -DCMAKE_MAKE_PROGRAM=D:/ProgramFile/ST/STM32CubeCLT_1.20.0/Ninja/bin/ninja.exe
cmake --build build

批量导出所有版本：
python ../../tools/export_project.py --project KQZL2 --batch --versions 1-14 -o ../../exports --clean --extras readme.txt,PRODUCT_SPEC.md

引脚连接：
- OLED: PB6(SCL), PB7(SDA)
- DHT11: PA5
- PM2.5 ADC: PA0
- PM2.5 LED: PA12 (低电平点亮)
- MQ-2 ADC: PA1 (版本5+)
- MQ-7 ADC: PA4 (版本11+)
- 风扇继电器: PA11
- 蜂鸣器: PA8
- LED灯光: PA6
- 按键: PB4(K1), PB5(K2), PB13(K3), PB14(K4)
- ESP8266: PB10(TX), PB11(RX), PB0(PD), PB1(RST)

- Flutter 主上位机: KQZL2_upper_ui_flutter，覆盖 v3/v4/v6/v7/v8/v10/v12/v13/v14
