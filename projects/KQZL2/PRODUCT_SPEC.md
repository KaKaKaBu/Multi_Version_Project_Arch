# KQZL2-001 PM2.5+排风+蜂鸣器+灯光 — 产品功能规格

基于 STM32F103C8T6 的 PM2.5 空气质量检测基础版本，支持 PM2.5 实时检测，并通过继电器排风、蜂鸣器和灯光完成超限提醒。

---

## 1. 项目概述

**项目编号:** KQZL2-001

**MCU:** STM32F103C8T6  
**显示:** OLED (SSD1306, I2C)  
**传感器:** PM2.5 (GP2Y1014AU)  
**执行器:** 继电器(风扇)、蜂鸣器、LED(灯光)  
**通信:** KQZL2-001/002/005/011 不含远程通信，KQZL2-003/006/012 支持 WiFi App，KQZL2-004/007/013 支持蓝牙 App，KQZL2-008/014 支持 WiFi 华为云 App，KQZL2-009 支持 WiFi vx 小程序，KQZL2-010 支持 WiFi 网页控制  

## 2. KQZL2-001 功能说明

**版本1:** PM2.5 + 排风 + 蜂鸣器 + 灯光

1. STM32F103C8T6 单片机进行数据处理。
2. OLED 液晶显示空气 PM2.5 实时数据。
3. GP2Y1014AU 检测当前 PM2.5 粉尘浓度。
4. 第一个按键 K1：切换自动模式、手动模式、阈值设置模式。
5. 手动模式下，第二个按键 K2 切换选中设备，第三个按键 K3 打开和关闭选中的设备。
6. 阈值模式下，第二个按键 K2 切换选中设置的阈值项，按键 K3 加，按键 K4 减。
7. 自动模式下，PM2.5 高于设定阈值时，继电器外接风扇打开进行排风，并启动蜂鸣器和灯光声光报警。

## 3. KQZL2-002 功能说明

**版本2:** 温湿度 + PM2.5 + 排风 + 蜂鸣器 + 灯光

1. STM32F103C8T6 单片机进行数据处理。
2. OLED 液晶显示空气 PM2.5、温湿度实时数据。
3. GP2Y1014AU 检测当前 PM2.5 粉尘浓度。
4. DHT11 温湿度传感器检测当前空气温湿度。
5. 第一个按键 K1：切换自动模式、手动模式、阈值设置模式。
6. 手动模式下，第二个按键 K2 切换选中设备，第三个按键 K3 打开和关闭选中的设备。
7. 阈值模式下，第二个按键 K2 切换选中设置某个阈值，按键 K3 加，按键 K4 减。
8. 自动模式下，PM2.5 高于设定阈值时，继电器外接风扇打开进行排风和声光报警；温度高于设定阈值时，继电器外接风扇打开进行排风和声光报警；湿度高于设定阈值时，继电器外接风扇打开进行排风和声光报警。

**版本14:** 温湿度 + 烟雾 + PM2.5 + CO + 排风 + 蜂鸣器 + 灯光 + WiFi + 华为云 app

1. STM32F103C8T6 单片机进行数据处理。
2. OLED 液晶显示空气 PM2.5、温湿度、烟雾实时数据。
3. DHT11 温湿度传感器检测当前空气温湿度。
4. GP2Y1014AU 检测当前 PM2.5 粉尘浓度。
5. MQ-2 烟雾传感器检测当前烟雾浓度。
6. MQ-7 传感器检测当前一氧化碳浓度。
7. 第一个按键 K1：切换模式自动模式、手动模式、阈值设置模式。
8. 手动模式下，第二个按键 K2 切换选中设备，第三个按键 K3 打开和关闭选中的设备。
9. 阈值模式下，第二个按键 K2 切换选中设置某个阈值，按键 K3 加，按键 K4 减。
10. 自动模式下，PM2.5 高于设定阈值时，继电器外接风扇打开进行排风和声光报警；温度高于设定阈值时，继电器外接风扇打开进行排风和声光报警；湿度高于设定阈值时，继电器外接风扇打开进行排风和声光报警；烟雾高于设定阈值时，继电器外接风扇打开进行排风和声光报警；一氧化碳高于设定阈值时，继电器外接风扇打开进行排风和声光报警。
11. ESP-01S WIFI 模块连接华为云 app，支持远程查看数据、远程设置阈值、远程控制排风/蜂鸣器/灯光开关。

## 9. 工作模式说明

### 5.1 自动模式 (AUTO)
- KQZL2-001 OLED 实时显示 PM2.5 数值；KQZL2-002/003/004 扩展显示温度、湿度；后续版本扩展显示烟雾、CO
- KQZL2-001 当 PM2.5 超过设定阈值时；KQZL2-002 当 PM2.5、温度或湿度超过设定阈值时；后续版本按已启用传感器阈值判断时:
  - 继电器吸合 (风扇启动排风)
  - 蜂鸣器鸣叫 (声光报警)
  - LED 点亮 (灯光报警)
- 传感器数值恢复正常后自动关闭设备

### 5.2 手动模式 (MANUAL)
- OLED 显示当前选中的设备 (风扇/蜂鸣器/灯光)
- K2 切换选中设备
- K3 打开或关闭选中设备

### 5.3 阈值设置模式 (THRESHOLD)
- OLED 显示当前选中的阈值项目
- KQZL2-001 K2 选择 PM2.5 阈值；KQZL2-002 扩展选择温度/湿度阈值；后续版本按启用传感器扩展烟雾/CO 阈值
- K3 增加阈值
- K4 减少阈值
